# Публикация soft-player-web

1. Тесты зелёные: `npm test` (или агент `test-runner`).
2. Если менялся состав файлов оболочки — `SHELL` в `sw.js`; при любом изменении приложения поднять номер в `CACHE`
   (`player-vN`), иначе старая версия может держаться на телефоне дольше.
3. Коммит в `main` (сообщение по-английски, Conventional Commits), затем `npm run deploy`.
4. Проверка через 1–2 минуты: `curl -s https://akmaks.github.io/soft-player-web/app.js | head -3` совпадает с локальным;
   статус Pages — `gh api repos/akmaks/soft-player-web/pages -q .status` (`built`).
5. Пользователю: на iPhone закрыть приложение смахиванием и открыть заново (иногда дважды — сервис-воркер
   подхватывает новую версию со второго запуска).

Репозиторий публичный — перед пушем убедиться, что в коммитах нет личных данных; автор коммитов — no-reply адрес GitHub.
